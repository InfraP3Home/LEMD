LEMD 1.7.6

Instalar en Kodi (una sola vez)

  1. Ajustes › Sistema › Add-ons → activa Orígenes desconocidos.
  2. Ajustes › Explorador de archivos › Añadir fuente → escribe https://infrap3home.github.io/LEMD/ y llámala LEMD.
  3. Ajustes › Add-ons › Instalar desde un archivo zip → LEMD → repository.lemd-1.0.0.zip.
  4. Instalar desde repositorio › Repositorio LEMD › Aspecto › Skin › LEMD → Instalar → acepta usar la skin.
  5. Opcional: en el mismo repositorio, Sonidos de la interfaz › LEMD · sonidos de cabina.

¿No te llega la última versión?

Desde la 1.7.6, LEMD se actualiza sola al abrir Kodi (una vez al día), la instalaras como la instalaras. Si tienes una versión anterior, pon la última una vez: Add-ons › Instalar desde repositorio › Repositorio LEMD › Aspecto › Skin › LEMD › Actualizar (o Instalar desde un archivo zip › LEMD con el zip de tu Kodi; se instala encima, sin perder tus ajustes). A partir de ahí ya no hace falta.

skin.lemd-1.7.6.zip Kodi 21 o superior

skin.lemd-1.7.6-kodi20.zip Kodi 20

Archivo del repositorio

repository.lemd-1.0.0.zip

Desde aquí las actualizaciones llegan solas: Kodi revisa el repositorio al arrancar y cada pocas horas (Ajustes › Sistema › Add-ons › Actualizaciones en «Instalar automáticamente»).
